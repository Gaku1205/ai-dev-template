# デザイン仕様

画面の見た目のルール（色・文字・形・文言・動き）。画面に触る作業では、ここに書かれた物だけを使う。

## 方針

- 避けること（「AIが作った感」の原因）：数字を大きく並べたタイル、角丸の箱を並べただけのカード、ピル型バッジの多用、グラデーション、絵文字、大きな塗りつぶしボタンの羅列

## 色

| 名前 | 値 | 用途 |
| --- | --- | --- |
| `--bg` | `#0A0A0B` | ページの背景 |
| `--text` | `#DEDFE3` | 本文 |
| `--muted` | `#9A9CA5` | 補足の文、ボタンの枠線 |
| `--line` | `#2C2D33` | 区切り線、入力欄の枠線 |
| `--error` | `#E5857D` | 入力まちがいのメッセージ |

## 文字

- 日本語は詰まって見えるので、11.5px より小さい文字は使わない
- 日本語は文節の途中で切らない（`word-break: auto-phrase`）

## 立て替え精算ページ（`/split`）

- 幅は 720px の中央寄せ。上から「精算」「人」「立て替えを記録」「記録」の順に、見出し（16px）と細い区切り線（`--line`）で分ける。箱やカードで囲まない
- ページ見出しは「立て替え精算」（24px）
- 精算の一覧は、記号なしの文章を縦に並べる（16px）。文言は「◯◯が△△に1,200円返す」。数字を大きくしたり色を付けたりしない。記録が無いとき：「立て替えを記録すると、ここに誰が誰にいくら返すかが出ます。」、全員貸し借りなしのとき：「貸し借りはありません。」
- 金額は3桁区切り＋「円」（例：1,200円）
- 入力欄は背景 `--bg`、枠線 `--line` の1px、文字 16px。ラベルは入力欄の上に 14px で置く
- ボタンは背景なし・枠線 `--muted` の1px・文字 14px（塗りつぶさない）。文言は「追加」「記録する」「削除」
- 記録の一覧は 14px。1行に「◯◯が1,200円（A、Bの分）　メモ」と、右端に「削除」ボタン
- 補足の文（記録がまだ無い、人が足りない）は `--muted`
- エラー文言は `--error`：「その名前はもう追加されています」「金額は1円以上の整数で入力してください」
- キーボードのフォーカスは 2px の `--text` の輪郭線で示す
