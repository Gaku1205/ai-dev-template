# 仕様書

アプリの「何を・どう動かすか」を書く。AIは作業の前に必ずここを読む。

## 目的

画面の光の広がりと縮みを見ながら、1分だけ深呼吸して気持ちを落ち着ける。ページを開いて「はじめる」を押すだけで使える。

## 前提

- 使う人：少し息を整えたい人。説明なしで使えること
- 技術：Next.js（App Router）＋TypeScript、テストはVitest

## 画面

### トップページ（`/`）

呼吸の流れは「吸う4秒 → 止める4秒 → 吐く6秒」の14秒を1周とし、60秒ちょうどで終わる（14秒の周期を4周と少し。最後の周期は途中で終わる）。

- 始める前：光（1つの円）は小さい状態で止まっている。「はじめる」ボタンがある
- 「はじめる」を押すと60秒が始まる
  - 吸うあいだ（4秒）光が広がる。止めるあいだ（4秒）大きさを保つ。吐くあいだ（6秒）光が縮む
  - いまの段階を文字で出す：「吸って」「止めて」「吐いて」
  - その段階の残り秒と、全体の残り秒を出す
- 60秒たつと自動で終わる。光は小さい状態に戻り、終わりの文言「おつかれさまでした」と「もう一度」ボタンを出す。「もう一度」で最初（0秒）からやり直す
- 動きを減らす設定（`prefers-reduced-motion`）の人には、光の拡大縮小をやめ、光は一定の大きさのまま、文字の案内だけで進める
- 段階の文字は画面読み上げにも伝わるようにする（`aria-live="polite"`）。毎秒の残り時間は読み上げ対象にしない

### 段階を決める関数（`src/lib/breathing.ts`）

経過秒から、いまの段階・その段階の残り秒・全体の残り秒・光の大きさ（0〜1）・終了したかを返す。光の大きさは、吸うで0→1、止めるで1、吐くで1→0（直線的に変化）。
