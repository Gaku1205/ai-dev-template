# 仕様書

アプリの「何を・どう動かすか」を書く。AIは作業の前に必ずここを読む。

## 目的

友達やルームメイトと立て替えたお金を記録して、「誰が誰にいくら返せばいいか」を一目で分かるようにする。

## 前提

- 使う人：立て替えが起きる少人数のグループの誰か1人が、まとめて入力する
- 保存：ブラウザの `localStorage`（サーバーなし、ログインなし）
- 金額：円の整数のみ。割り勘は対象者での均等割りのみ
- 技術：Next.js（App Router）＋TypeScript、テストはVitest

## 画面

### 立て替え精算（`/split`、トップページからリンクする）

- 人の名前を追加できる（同じ名前は追加できない）
- 人が2人以上いると、立て替えを記録できる：立て替えた人・金額（1円以上の整数）・誰の分か（複数選択。選ばなければ全員）・メモ
- 記録の一覧が見え、1件ずつ削除できる
- 一番上の「精算」に、「◯◯が△△に1,200円返す」の一覧を出す。記録を追加・削除するたびにすぐ更新する
- 精算は、各人の収支（立て替えた額−負担額）を出し、払う側と受け取る側を大きい額どうしで突き合わせて、送金回数を少なくする。送金をすべて実行すると全員の収支が0円になる
- 割り切れない金額の端数は、その記録の「誰の分か」の並び順で先頭の人から1円ずつ負担する
- 人と記録は `localStorage` に保存し、開き直しても残る
